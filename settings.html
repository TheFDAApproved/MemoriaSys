CSV Import Instructions

Upload a .csv file only. The first row must contain all the column names exactly as shown below, even if some cells are left blank.

  • The only required values are control_number and deceased_name.
  • If you include block_name and grave_code, they must both be filled and the grave must already exist in the system.
  • status can only be Active or Inactive. Pending rows are created through Reserve, not through CSV.
  • assistance_type can only be Burial, Transfer the remains of the late, or Other.
  • deceased_sex can only be Male, Female, or Unknown.
  • Dates can be written like 2024-01-15, 01/15/2024, or Jan 15 2024.
  • If a control_number already exists, that row updates the existing record. Only the cells you fill in are applied — empty cells keep the current value.
  • row_num and col_num are shown for reference only and are ignored on import.
  • Leave cells empty if you do not have the information.

Exact header row for the CSV file: 

                                        control_number,deceased_name,last_known_address,death_certificate,deceased_date_of_birth,deceased_date_of_death,deceased_sex,block_name,grave_code,row_num,col_num,contact_person_name,contact_person_phone_number,contact_person_email,contact_person_address_barangay,contact_person_address,assistance_type,burial_permit_number,burial_permit_date,transfer_permit_number,transfer_permit_issued_by,transfer_permit_date,exhumation_permit_number,exhumation_permit_date,date_buried,date_exhumed,burial_clearance_date,lease_expiration_date,status,remarks

Database Backup & Restore

Please read before restoring

Restoring a backup replaces all current data. Make sure nobody else is using the system. The process may take a few minutes to finish. The system keeps the 5 most recent backups. Creating a new one replaces the oldest.
